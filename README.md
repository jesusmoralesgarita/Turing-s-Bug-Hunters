# Tinta Nómada

## Descripción del proyecto
**Tinta Nómada** es una plataforma web diseñada para facilitar la **gestión de pedidos personalizados** y mejorar la comunicación entre el negocio y sus clientes.  

El objetivo principal es ofrecer una experiencia sencilla, eficiente y cercana para que los usuarios puedan:
- Explorar productos personalizados  
- Solicitar cotizaciones  
- Gestionar pedidos  
- Comunicarse directamente con el negocio  

La plataforma está enfocada en personas que buscan **regalos únicos para ocasiones especiales**, como cumpleaños, aniversarios o graduaciones.

---

## Propuesta de valor
- Administración eficiente de pedidos  
- Comunicación directa con el negocio  
- Catálogo de productos personalizados  
- Cotización rápida y accesible  
- Experiencia centrada en el cliente  

---

## Funcionalidades principales
- Página de inicio con catálogo y reseñas  
- Registro e inicio de sesión de usuarios  
- Perfil de usuario con historial de compras  
- Catálogo por categorías  
- Carrito de compras  
- Subida de diseños personalizados  
- Gestión de pedidos  
- Página de contacto  
- Sección de descuentos  

---

## Tecnologías utilizadas

### Frontend
- **HTML** → Estructura semántica y accesibilidad  
- **CSS** → Estilos y diseño visual  
- **Bootstrap** → Diseño responsivo y componentes UI  
- **JavaScript** → Interactividad y lógica en cliente  

### Backend
- **Java** → Lenguaje principal del servidor  
- **Spring Boot** → Desarrollo de API REST y lógica del sistema  

### Base de datos
- **MySQL** → Gestión y almacenamiento de datos  

### Herramientas y control de versiones
- **Git** → Control de versiones  
- **GitHub** → Repositorio y colaboración  
- **Postman** → Pruebas de endpoints

## Planificación del proyecto
El desarrollo se organizó en 3 sprints principales:

- **Sprint 1:** Planeación, diseño, wireframes y primeras páginas  
- **Sprint 2:** Desarrollo frontend e interacción de usuarios  
- **Sprint 3:** Backend, base de datos e integración completa
